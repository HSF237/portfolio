# Muhammad Hasan — Portfolio

> Code is a canvas. A website is art.

Personal portfolio of Muhammad Hasan, full-stack JavaScript developer and founder & CEO of Tech Orbit Hub.

## Highlights
- Three.js shader blob (simplex-noise displacement, iridescent fresnel) that reacts to scroll, speed, pointer and device tilt
- GSAP ScrollTrigger choreography: variable-font stretching, word-by-word reveals, stacking project cards, pinned "14" scene
- Real desktop / tablet / phone screenshots of client sites in device mockups
- Scroll-velocity skew, magnetic buttons, custom cursor, optional Web Audio UI sounds
- Resume viewer with tap-to-zoom and PDF download
- Mobile-first, light & dark themes, respects reduced motion
- Easter egg: type `chaos` (or tap the MH logo five times)

## Stack
HTML, CSS, vanilla JavaScript, Three.js r128, GSAP 3 + ScrollTrigger. No build step.

## Run locally
Open `index.html` in a browser, or serve the folder:
```bash
npx serve .
```
